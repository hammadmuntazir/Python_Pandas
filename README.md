# Python and pandas Practice Projects

A collection of Python exercises and small data projects covering data extraction, cleaning, aggregation, feature engineering, and exploratory analysis.

## Project highlights

### 1. Global country data analysis
Explores a country dataset with 64 attributes, including population, regions, economic indicators, and democracy-related fields. The project notes and script are in [Project_Data_Extraction](./Project_Data_Extraction/).

### 2. Anime feature extraction
Parses episode and runtime information from text fields and creates additional features for analysis. See [Project_Feature_Extraction](./Project_Feature_Extraction/).

### 3. Flight data analysis
A separate project folder is available at [flight-data-analysis](./flight-data-analysis/).

## Learning exercises

The repository also contains smaller examples for:
- DataFrame basics and common operations
- Data cleaning
- Group-by aggregation and pivot tables
- Correlations and plotting

## Tech stack

- Python
- pandas
- NumPy

## Getting started

Use Python 3.10 or newer. Install the libraries used by the script you want to run:

```bash
python -m pip install pandas numpy
```

Then open the relevant project folder and run its Python script. For example:

```bash
python Project_Data_Extraction/dataextraction.py
python Project_Feature_Extraction/featureextraction.py
```

These are learning and analysis projects rather than a packaged Python application; individual folders may have their own input files and instructions. Check each folder before running a script.
